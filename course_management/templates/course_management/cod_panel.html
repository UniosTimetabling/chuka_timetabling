Create Student Group

Create teaching groups for a program cohort (e.g. BSc Computer Science — Year 1 — Group A). Compulsory courses get split per group so they can be scheduled concurrently; electives and specialization-stem courses always stay shared across every group. Each group's course gets that group's letter appended to its code (e.g. EDFO 111-A, EDFO 111-B) so they're distinguishable at a glance — existing rows are corrected automatically if the letter is missing or wrong.

How many groups to create at once. Leave as 1 for a single group, or enter e.g. 3 to add three rows below — each created and populated in turn.
Code: 1-4 letters/numbers (e.g. A or DA). Name is optional — leave blank to use "Group [Code]".
Only compulsory (non-elective, non-specialization-stem) courses are ever split into groups — electives and stem courses remain shared by construction.
This list includes units already split into other groups — pick the ones this new group should also get.

Add Course(s) to Group(s)

Pick a program/year/semester, choose which of its existing groups should get the course(s) — all of them or just some — and each selected course is added to every group you ticked. The list below is pulled from the program's full curriculum (including units with no allocation yet, and electives), and each group automatically gets its own lettered version of the course code. Groups that already have a course get their letter suffix corrected instead of a duplicate row.

Create Groups (All Program Years)

Pick a program and set how many groups to create per year — every semester found for that year gets the same group codes. Untick a year (e.g. Year 2 and Year 4) to skip it entirely, or leave its group count at 0. All compulsory units for each year/semester are split across its groups automatically, with course codes getting the group's letter suffix (e.g. EDFO 111-A) just like a single group create.

Select a Program to see its years.

Copy Groups to Other Years

Already built groups for one year (e.g. Year 1) and every other year repeats the same split (common for programs like B.Ed where Year 1–4 all use Group A / Group B / …)? Pick the program, choose the year to copy from, then tick the year(s) to copy to. Each target year gets the same group codes, with its own courses split into them automatically — same as building it by hand. Groups that already exist are skipped safely, so this is safe to re-run.

Select a Program to see its existing groups.
