📋 File Format & Template

Required columns (only 2):
  • reg_no — Student registration number in any format (e.g. EB1/66791/23, SCH/12345/22, or plain 66791)
  • course_code — Course code exactly as in the system (e.g. CSC301, MATH201)
✅ program_name, student_name, and department are not required — the system resolves them automatically by looking up the course code across all programs university-wide.
🔍 Registration numbers are normalised automatically — only the numeric portion is used for duplicate detection (e.g. "EB1/66791/23" → "66791").
📁 Supported formats: .csv and .xlsx / .xls
