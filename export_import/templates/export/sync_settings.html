Certificate Pinning (recommended for a self-signed remote)

The stronger alternative to turning off "Verify SSL" above. Fetch the remote's current certificate, confirm its fingerprint matches what the remote actually presents (e.g. run openssl x509 -in cert.pem -noout -fingerprint -sha256 directly on the remote machine, or check its web server config), then pin it. Every sync request after that re-checks the live certificate against this pin and refuses to send data if it ever changes unexpectedly.
