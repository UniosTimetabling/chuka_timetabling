Optimise Venue Assignments per Timeslot

Within each day + timeslot, courses are reassigned to venues so that those with more students receive venues with larger capacity. Courses are never moved to a different day or time — only the venue within the same slot changes.

Move All Courses Out of

Every course currently booked in this venue is placed elsewhere automatically: first the same day & timeslot in the closest-capacity free venue; if none is free there, the nearest fully conflict-free day/timeslot/venue; if nothing is fully clean either, the same day in any venue that is at least not double-booked (flagged below for manual review). Blocked and specialized venues are never used as a destination.
